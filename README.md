# Anotida's birthday page

A small, responsive birthday postcard for Anotida. It is plain HTML, CSS, and JavaScript, so it needs no build step.

## Publish free with GitHub Pages

1. Create a **public** repository on GitHub.
2. Upload `index.html`, `README.md`, and the `assets` folder. Keep the folder structure as it is.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.
5. GitHub will show the page URL in that same Pages section after publishing.

The published page and its photos will be public. Anyone who has the link can view them.
